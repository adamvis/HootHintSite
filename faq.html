FAQ

Common questions about setup, cost, and how HootHint behaves.

General

Is HootHint free?

Yes — HootHint itself is free to use. You'll bring your own free Google Gemini API key (see Getting Started), which has its own no-cost tier with a request-per-minute limit. HootHint doesn't charge anything on top of that, and never sees your key — it's stored only in a local .env file on your own machine.

Do I need to know how to code?

No. Download the installer, run it, and follow the setup window — no terminal or config files required.

What Windows versions are supported?

Windows 10 and 11. HootHint isn't tested on other platforms.

Setup

Why does Windows show a "Windows protected your PC" warning?

That's Microsoft SmartScreen's "unrecognized publisher" warning — it appears for any app not signed with a paid certificate (which costs real money per year to maintain), regardless of whether the app is safe. Click More info → Run anyway to continue. If you'd rather verify first, compare the download against the file listed on the official Releases page.

My antivirus flagged the installer or the app — is that expected?

It can happen with any small, freshly-built, unsigned Windows app — heuristic scanners are more suspicious of binaries with no track record. Check Windows Security → Virus & threat protection → Protection history for details on what was flagged. If you'd rather sidestep this entirely, you can run HootHint from source instead (see the source repository) — that never produces a standalone binary at all.

Do I need my own Telegram bot?

Not strictly — a shared default bot works out of the box for on-screen popup notifications, and for Telegram too if you'd rather not set anything up. But Telegram's /stop command and QR-code linking rely on a single update queue per bot; if many people use the shared bot at the same time, one person's poll can occasionally consume an update meant for someone else, causing a missed /stop or QR link. Creating your own bot (via @BotFather, /newbot — under a minute) avoids this entirely, since it's the only thing polling it. It's offered as an option in the setup window, not a requirement.

Do I need my own Gemini API key, or is one built in?

You need your own — HootHint doesn't ship with (or have access to) anyone else's key. This keeps your usage, quota, and any costs entirely separate from every other HootHint user. Get one free at aistudio.google.com/apikey.

Using it

I'm getting rate-limit errors — what now?

The free Gemini tier has a per-minute request cap that varies by account and model — sometimes as low as 5 requests/minute. Raise the "time between screenshots" value in the setup window, or check your actual quota at aistudio.google.com/rate-limit.

How do I stop a run?

Right-click the tray icon (near the clock, under the "^" arrow) and choose Stop, press Ctrl+C in the console window if it's visible, or send /stop from your linked Telegram account.

What data does HootHint send anywhere?

Only the screenshots of the region you selected — sent to Google's Gemini API (with your key) and, if you've set it up, to Telegram. See the full Privacy page for details.

Where do I report a bug or ask something not covered here?

Open an issue on the HootHint issue tracker.
