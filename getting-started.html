Getting Started

From download to your first answer, in about five minutes.

  1. Download and run the installer

    Download HootHint-Setup.exe and run it. It installs to your own user folder — no admin rights needed. Pick a Start Menu / desktop shortcut if you'd like one, then finish the wizard.

    Windows may show a blue "Windows protected your PC" SmartScreen screen the first time, since this isn't signed by a paid certificate authority. Click More info → Run anyway. See the FAQ for why this happens and how to confirm the download is legitimate.

  2. Get a free Gemini API key

    HootHint answers questions using Google's Gemini API — with your own key, not one built into the app. Go to aistudio.google.com/apikey, sign in with a Google account, and create a key. It's free, and takes under a minute.

  3. Launch HootHint and finish setup

    On first launch, a small setup window asks for that Gemini key — paste it in. Notifications default to an on-screen popup, so you can stop here and press Start.

    Want alerts on your phone instead (or as well)? Message @BotFather on Telegram, send /newbot, and paste the token it gives you into the bot token field — then click Link via QR… and scan the code with your phone's Telegram app. A shared default bot also works with no setup at all, for a quick try — see the FAQ for the trade-off.

  4. Choose your timing and subject

    The main setup window lets you set how often HootHint captures the screen, how many recent captures it remembers (useful if a question spans a scroll), and a subject hint to help Gemini interpret what it sees. Defaults are sensible — just click Start if you're not sure.

  5. Drag to select a region

    Your screen dims; click and drag a rectangle around the area you want watched. HootHint then starts capturing that region on its own, and minimizes to a tray icon (near the clock, under the "^" arrow).

  6. Watch for answers — and stop any time

    Answers appear as a popup in the bottom-right corner, or as a Telegram message, depending on what you chose. To stop, right-click the tray icon and choose Stop, press Ctrl+C in the console (if visible), or send /stop on Telegram.
