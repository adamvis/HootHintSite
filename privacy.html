Privacy

HootHint has no servers of its own. Everything below is the complete list of where your data goes.

What's captured

Only the screen region you drag-select when a run starts. HootHint never captures your full screen, other windows, or anything outside that region, and never captures anything before you've selected a region and clicked Start.

Where it goes

Google Gemini API

Each captured image is sent to Google's Gemini API, using your own API key — never a key belonging to HootHint or any other user. That request is subject to Google's own terms and privacy policy, not HootHint's. In particular, Google's free tier allows using submitted content to improve their products, unlike their paid tier — review Gemini API's terms if that matters for what you're capturing.

Telegram (optional)

If you've configured Telegram notifications, the same captured images and the answer text are also sent via the Telegram Bot API to the chat you linked. This only happens if you've set up Telegram — it's off by default in favor of the on-screen popup. Subject to Telegram's own privacy policy.

What stays on your device

Captured images are also written to a local snapshots folder next to the app, purely as working storage for the run in progress — HootHint deletes each one once it's no longer needed to answer the current question. Your Gemini key and Telegram credentials are stored only in a local .env file next to the app; nothing is uploaded to any HootHint-operated service, because there isn't one.

What HootHint's developer sees

Nothing. There's no telemetry, analytics, crash reporting, or phone-home behavior of any kind built into the app. The only outside parties involved are Google (via your key) and, optionally, Telegram — both described above.
